# Índice

# 1. Introducción

La evolución de los proyectos cloud, inteligencia artificial, automatización y modernización tecnológica ha impulsado la necesidad de adoptar modelos de gestión más ágiles, iterativos y orientados a la entrega continua de valor.

En escenarios donde existen iniciativas de rápida ejecución, alta incertidumbre técnica, validaciones tempranas o necesidad de acelerar resultados, los modelos tradicionales de gestión pueden generar sobrecarga operacional, complejidad documental y menor capacidad de adaptación.

El presente Framework Ágil Corporativo de Morris & Opazo establece un modelo de gestión diseñado para proyectos de corta y mediana duración, permitiendo mantener control organizacional, trazabilidad, gobernanza y visibilidad ejecutiva, sin perder flexibilidad operativa.

Este framework complementa el modelo corporativo tradicional de gestión de proyectos, incorporando prácticas ágiles, mecanismos de iteración continua y estructuras livianas de ejecución enfocadas en:

Entrega incremental

Validación temprana

Mejora continua

Colaboración activa

Adaptación rápida al cambio

Foco permanente en generación de valor

El modelo es aplicable especialmente a iniciativas POCs, assessments, workshops, MVPs, capacitaciones técnicas, proyectos AI/ML y migraciones ágiles.

# 2. Alcance del Framework

El objetivo del presente Framework Ágil Corporativo es establecer un modelo organizacional, metodológico y operativo que permita gestionar proyectos tecnológicos de manera adaptable, colaborativa y orientada a resultados, manteniendo alineación con las capacidades técnicas y estratégicas de Morris & Opazo.

Este Framework aplica a proyectos tecnológicos ejecutados bajo modelos iterativos, de rápida implementación o enfocados en validación temprana de soluciones.

Este framework cubre iniciativas como:

Automatización

El modelo establece lineamientos para:

El framework no reemplaza el modelo corporativo tradicional de gestión de proyectos, sino que actúa como complemento metodológico para proyectos que requieren mayor adaptabilidad y velocidad de ejecución.

El objetivo de este Framework se enfoca en acelerar la entrega de valor mediante ciclos de ejecución más cortos y enfocados en resultados concretos, reduciendo tiempos de implementación y facilitando una respuesta más rápida a las necesidades del cliente. Asimismo, promueve una mayor capacidad de adaptación frente a cambios funcionales, técnicos u operacionales, permitiendo ajustar prioridades y enfoques de trabajo de manera continua. Adicionalmente, el modelo fomenta la colaboración permanente entre equipos técnicos, áreas de gestión y stakeholders, fortaleciendo la comunicación, la visibilidad operacional y la toma de decisiones durante todo el ciclo de vida del proyecto.

# 3. Principios del Modelo Ágil

## 3.1 Entrega Continua de Valor

El framework promueve entregas tempranas y continuas, priorizando resultados funcionales y validaciones frecuentes sobre ciclos extensos de planificación.

## 3.2 Adaptabilidad Operativa

El modelo permite ajustar prioridades, backlog y enfoque técnico conforme evolucionan las necesidades del cliente o del proyecto.

## 3.3 Validación Temprana

Las iniciativas deben incorporar validaciones periódicas con stakeholders para reducir incertidumbre y acelerar la toma de decisiones.

## 3.4 Colaboración Continua

La coordinación permanente entre cliente, PM, PMO y Cloud Team es fundamental para asegurar alineación y continuidad operacional.

## 3.5 Simplicidad Operativa

El framework promueve estructuras livianas de documentación, priorizando artefactos realmente necesarios para control, trazabilidad y entrega.

## 3.6 Mejora Continua

Cada iniciativa debe incorporar mecanismos de retrospectiva y aprendizaje continuo que permitan optimizar prácticas, procesos y ejecución futura.

# 6. Roles Y Responsabilidades de cada equipo del Framework

El Framework Ágil Corporativo de Morris & Opazo se estructura sobre un modelo de gobernanza adaptable, orientado a facilitar la ejecución rápida, colaborativa e iterativa de iniciativas tecnológicas, manteniendo al mismo tiempo control organizacional, trazabilidad y visibilidad operacional.

Este modelo define roles claros, responsabilidades diferenciadas y mecanismos de coordinación continua entre áreas técnicas, PMO, stakeholders y equipos de cliente, permitiendo una gestión eficiente de proyectos de rápida ejecución, alta adaptabilidad y validación incremental.

Los roles establecidos dentro del framework no sólo representan funciones organizacionales, sino también niveles de responsabilidad y toma de decisiones dentro del ciclo de vida ágil del proyecto, abarcando desde la supervisión estratégica y gobernanza ejecutiva hasta la coordinación operativa, gestión iterativa y ejecución técnica especializada.

# 7. Roadmap Ágil del Proyecto

## 7.1 Agile Intake & Handover

La fase de Agile Intake & Handover corresponde al proceso inicial de recepción, validación y transferencia operativa de la iniciativa desde el área comercial hacia el equipo de ejecución. Esta etapa tiene como objetivo asegurar que el proyecto ingrese correctamente estructurado al framework ágil, contando con la información mínima necesaria para iniciar el assessment, POC, capacitación o iniciativa cloud.

Durante esta fase se debe consolidar:

El requerimiento comercial

Objetivos preliminares

Alcance esperado

Contexto del cliente

Stakeholders involucrados

Sponsor y contraparte técnica

Plazos estimados

Entregables esperados

Adicionalmente, se debe realizar la asignación formal del equipo de preventa, Project Manager y equipo técnico responsable, considerando el tipo de iniciativa y las capacidades técnicas requeridas, tales como arquitectura cloud, seguridad, Kubernetes, GenAI, modernización, migración o data platforms.

Como parte del proceso de handover, el equipo comercial y preventa deberá transferir al equipo operativo toda la información levantada durante la etapa comercial, incluyendo antecedentes técnicos, expectativas del cliente, restricciones conocidas, riesgos iniciales y dependencias identificadas.

El framework establece como referencia que este tipo de iniciativas ágiles deberán considerar una duración objetivo no superior a cuatro semanas, salvo casos excepcionales justificados por complejidad técnica o alcance.

El Agile Intake también debe considerar:

Identificación de stakeholders del cliente

definición de sponsor y contraparte técnica

estimación preliminar de plazos

validación inicial de capacidades técnicas

identificación de dependencias relevantes

definición preliminar de entregables esperados

## 7.4 Ejecución Iterativa

La fase de Ejecución Iterativa corresponde al desarrollo progresivo de las actividades definidas en el backlog del proyecto, priorizando entregas incrementales, validaciones continuas y rápida adaptación frente a cambios o nuevos requerimientos. Durante esta etapa, el equipo técnico ejecuta las tareas comprometidas en coordinación permanente con el cliente y stakeholders, manteniendo seguimiento continuo del avance, riesgos, bloqueadores y cumplimiento de los objetivos definidos para cada iteración o sprint.

Desarrollo

Configuración

Workshops

Validaciones

Seguimiento continuo

## 7.5 Validación Continua

Demos

Feedback cliente

Ajustes backlog

Validación entregables

## 7.6 Cierre

La fase de Cierre Ágil corresponde a la validación final de la iniciativa y formalización de los entregables comprometidos, asegurando que los objetivos definidos hayan sido cumplidos y validados junto al cliente. Esta etapa contempla la consolidación de resultados, presentación ejecutiva de cierre, validación de entregables técnicos y transferencia de conocimiento o documentación generada durante el proyecto. Adicionalmente, el cierre debe incluir lecciones aprendidas, identificación de mejoras y definición de posibles iniciativas futuras, permitiendo mantener continuidad operativa y trazabilidad organizacional sin generar sobrecarga documental innecesaria.

# 8. Conclusión

El presente Framework Ágil Corporativo proporciona un modelo estructurado y adaptable para gestionar iniciativas cloud, AI, POCs, assessments, capacitaciones y proyectos de rápida ejecución.

El framework permite mantener equilibrio entre flexibilidad operacional y gobernanza corporativa, facilitando entregas rápidas, colaboración continua y generación temprana de valor.

Su implementación busca fortalecer la capacidad de Morris & Opazo para ejecutar proyectos ágiles de forma consistente, escalable y alineada con las necesidades de clientes, equipos técnicos y objetivos organizacionales.
