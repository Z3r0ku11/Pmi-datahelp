## 4. ROLES Y RESPONSABILIDADES

### 4.1 Project Management Office (PMO)
- **ID:** ROL-001
- **Nombre:** Project Management Office
- **Propósito:** Gobierno del modelo corporativo de gestión de proyectos
- **Responsabilidades:**
  - Definir y mantener el framework
  - Liderar el proceso de PMO Intake
  - Validar información base del proyecto
  - Clasificar proyectos según criticidad
  - Consolidar dashboards y KPIs
  - Supervisar cumplimiento metodológico
  - Proveer visibilidad ejecutiva
  - Canalizar el escalamiento organizacional
- **Fases relacionadas:** PHA-001 (PMO Intake), PHA-006 (Monitoreo y Control)
- **Procesos relacionados:** PROC-001, PROC-006
- **Fuente:** Página 8-9, 11-12

### 4.2 Líder de Jefes de Proyecto (PM Lead)
- **ID:** ROL-002
- **Nombre:** Líder de Jefes de Proyecto / Team Leader de Proyectos
- **Propósito:** Nivel táctico del framework, coordinación y supervisión de Project Managers
- **Responsabilidades:**
  - Liderar el proceso de Handover
  - Validar consistencia entre SOW, alcance y entregables
  - Supervisar al equipo de Project Managers
  - Monitorear la salud operacional del portafolio
  - Detectar desviaciones tempranas
  - Facilitar resolución de bloqueos
  - Asegurar correcta aplicación del framework
  - Validar calidad de planificación y ejecución
  - Escalar riesgos críticos hacia PMO
- **Fases relacionadas:** PHA-002 (Handover), PHA-006 (Monitoreo)
- **Procesos relacionados:** PROC-002, PROC-006
- **Fuente:** Página 9, 12-14

### 4.3 Project Manager (PM/JP)
- **ID:** ROL-003
- **Nombre:** Project Manager / Jefe de Proyecto
- **Propósito:** Responsable directo de la gestión integral del proyecto durante todo su ciclo de vida
- **Responsabilidades:**
  - Construir WBS y cronograma
  - Configurar proyecto en Asana
  - Coordinar equipo técnico
  - Gestionar riesgos y cambios
  - Realizar reportería
  - Liderar reuniones
  - Mantener comunicación con cliente
  - Gestionar hitos y entregables
  - Coordinar cierre técnico y administrativo
- **Fases relacionadas:** PHA-003 a PHA-008
- **Procesos relacionados:** PROC-003 a PROC-008
- **Fuente:** Página 10, 14-15

### 4.4 Cloud Team (Equipo Técnico)
- **ID:** ROL-004
- **Nombre:** Cloud Team / Equipo Técnico
- **Propósito:** Arquitectos, ingenieros cloud y especialistas técnicos responsables de ejecutar actividades técnicas
- **Responsabilidades:**
  - Ejecutar tareas técnicas
  - Participar en estimación de HH
  - Validar factibilidad técnica
  - Apoyar la construcción del WBS
  - Generar documentación técnica
  - Reportar avance al PM
  - Levantar riesgos técnicos
  - Elaborar IDD
  - Participar en validaciones
- **Fases relacionadas:** PHA-001 (asignación), PHA-003 a PHA-008
- **Procesos relacionados:** PROC-003 a PROC-008
- **Fuente:** Página 10-11

### 4.5 Stakeholders del Proyecto
- **ID:** ROL-005
- **Nombre:** Stakeholders del Proyecto
- **Propósito:** Actores internos y externos con interés o impacto en el proyecto
- **Responsabilidades:** Definidas por Project Manager según el proyecto
- **Fases relacionadas:** Transversal
- **Fuente:** Página 11

### 9.1 Niveles de Governance Identificados

El Framework establece **3 niveles** de governance claramente diferenciados:

#### **Nivel Estratégico - PMO**
- **Responsable:** Project Management Office
- **Función:** Gobierno del modelo corporativo
- **Alcance:** Portafolio organizacional
- **Actividades:**
  - Definición y mantenimiento del framework
  - PMO Intake y validación inicial
  - Consolidación de KPIs y dashboards
  - Visibilidad ejecutiva
  - Escalamiento organizacional
- **Fuente:** Página 11-12

#### **Nivel Táctico - Líder de Jefes de Proyecto**
- **Responsable:** Líder de Jefes de Proyecto / PM Lead
- **Función:** Supervisión y coordinación operativa
- **Alcance:** Portafolio operativo
- **Actividades:**
  - Handover y transferencia
  - Supervisión metodológica
  - Monitoreo salud operacional
  - Detección temprana desviaciones
  - Escalamiento operativo
- **Fuente:** Página 12-14

#### **Nivel Operativo - Project Manager**
- **Responsable:** Project Manager
- **Función:** Ejecución integral del proyecto
- **Alcance:** Proyecto individual
- **Actividades:**
  - Planificación y configuración
  - Coordinación técnica
  - Control de ejecución
  - Gestión de stakeholders
  - Cierre del proyecto
- **Fuente:** Página 14-15
